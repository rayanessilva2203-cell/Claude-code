# Design system — Escrita Divônica

## Formatos
| Peça | Tamanho | Área segura |
|---|---|---|
| Carrossel / post | 1080 × 1350 px (4:5) | 60 px nas bordas |
| Capa de Reels | 1080 × 1920 px | Texto entre 420 px e 1500 px de altura (aparece no grid 4:5) |
| Story | 1080 × 1920 px | 250 px livres no topo e na base |

## Tipografia (opções gratuitas no Canva)
| Camada | Estilo | Sugestões | Tamanho relativo |
|---|---|---|---|
| Microtopo | Sans fina, caixa alta, espaçamento +300 | Montserrat Light, Glacial Indifference | 1× (≈ 18 px) |
| Script | Manuscrita fluida | Allura, Sacramento, Great Vibes, Hello Paris Script | 6× |
| Display (gatilho) | Sans grossa e arredondada | Fredoka Bold, Poppins Black, Agrandir Heavy, Nunito Black | 8–10× |
| Serif editorial (alternativa) | Serif itálica de contraste | Playfair Display Italic, DM Serif Display | 7× |
| Tag | Sans média | Poppins Medium/Bold | 2,5× |
| Impacto | Sans pesada, sublinhada | Montserrat ExtraBold | 3× |

Regra: **no máximo 3 famílias por peça** (script + display + sans de apoio).

## Paleta
| Nome | Hex | Uso |
|---|---|---|
| Creme-manteiga | `#F6EFA6` | Palavra-gatilho, linha de impacto |
| Rosa-chiclete | `#D65DB1` | Tag de destaque, corações |
| Rosa-claro | `#F7C8E0` | Contorno de recorte, flores |
| Branco | `#FFFFFF` | Script, estrelas, borda tracejada |
| Cinza-quente | `#8E8A85` | Fundo / clima da foto |
| Café | `#5B4636` | Variação para fotos de café/madeira |
| Azul-pasta | `#3AA0E8` | Ícone de pasta, balões de chat |

Variações por clima da foto:
- **Foto clara/fria** → display creme + tag rosa.
- **Foto quente (café, madeira)** → display creme + serif itálica branca + tag rosa.
- **Foto escura (elevador, noite)** → display creme com sombra leve 20% preta.

## Efeitos-assinatura
1. **Texto atrás da cabeça** — duplicar foto, remover fundo na cópia, colocar o texto entre as duas.
2. **Recorte sticker** — remover fundo + contorno (Canva: Sombras → Contorno) branco ou rosa-claro, 10–15 px.
3. **Tag tracejada** — retângulo rosa + borda tracejada branca 2 px, leve rotação de −2° a −4°.
4. **Texto curvo** — Efeitos → Curva, 30–50, para a palavra display.
5. **Textura lorem ipsum** — bloco de texto 9 px, 40% opacidade, lateral da foto.
6. **Elementos de interface** — pastas coloridas ("Design", "Conteúdo"), barra "Copy / Paste / Share",
   botão de câmera, cursor — fazem o post parecer "dentro do celular".
7. **Estrelinhas** — 3 a 5 estrelas de 4 pontas brancas em tamanhos diferentes.

## Grid do feed
- Alterne: **rosto grande** → **objeto (café/mão/pés)** → **rosto com texto display**.
- Mantenha o creme e o rosa em toda capa para o feed ficar reconhecível de longe.
- Capas de Reels com ícone ▶ devem ter o texto dentro da área 4:5.
