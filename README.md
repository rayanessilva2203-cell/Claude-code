# claude-code

Skills do Claude Code para criação de conteúdo.

## Skills

### `escrita-divonica`
Copy + direção de design para posts, carrosséis, capas de Reels e stories de Instagram
em estilo de feed estético: headlines em camadas, linguagem de amiga, gírias fofas e foco em Canva.
Feita para perfis em crescimento.

- [`SKILL.md`](.claude/skills/escrita-divonica/SKILL.md): regras de escrita, anatomia da capa, fórmulas, processo e formato de entrega
- [`banco-de-headlines.md`](.claude/skills/escrita-divonica/references/banco-de-headlines.md): headlines originais com nota
- [`design-system.md`](.claude/skills/escrita-divonica/references/design-system.md): fontes, cores, tamanhos e efeitos

**Como usar:** abra o Claude Code neste repositório e peça, por exemplo:
> "Crie 5 ideias de carrossel para meu perfil de confeitaria usando a escrita divônica"

ou chame diretamente `/escrita-divonica`.
